# [db] Replace the in-memory store with a SQLAlchemy database store
**What:** Replace `Store` (in-memory) and the raw-`sqlite3` `SqliteStore` ([#015](done/015-api-persistence.md)) with one `StoreProtocol` implementation on SQLAlchemy, SQLite by default. The database is chosen by one environment variable holding a SQLAlchemy URL (replaces `FERNSLOP_DB_PATH`), and nothing outside the connection setup may be SQLite-specific, so Postgres can be added later ([#130](parked/130-db-postgres.md)). Routers stay untouched.
**Why:** The user asked for a real database via SQLAlchemy that is database-agnostic; today the default store loses all data on restart and the persistent one is stdlib-only and SQLite-bound. Adding the `sqlalchemy` dependency is explicitly approved by the user.
**Edge cases:** `transaction()` must stay atomic, re-entrant and exclusive under threads (undo and 50-plant limit checks, see #015); photos (bytes), `undo_payload`, insertion order, feed-order ties and case-insensitive follow emails must behave as before; seed once on an empty DB, `reset()` restores it; `photo_cleanup` and `digest.main()` must use the configured DB; tests must not touch a developer's real DB file; schema is created with `create_all` (migrations are [#140](parked/140-db-migrations.md)).
