# [audit] Strip photo metadata and harden photo responses
**What:** Remove EXIF/XMP metadata (GPS, device, timestamps) from uploaded JPEG/PNG/WebP before storing, and serve photos with `X-Content-Type-Options: nosniff` and `Content-Disposition: inline`; also stop a post from attaching a photo uploaded by another device (or the seed photo). Covers audit 7 and 14 (fourth bullet).
**Why:** `audit.md` 7: phone photos carry GPS, so posting a garden photo publishes a home location to anyone with the public URL (cached immutable for a year); 14: a post can reference anyone's not-yet-posted upload.
**Edge cases:** Open question: adding Pillow needs the user's approval (`AGENTS.md`); a stdlib stripper is possible but dropping EXIF loses JPEG orientation, so phone photos would display rotated unless orientation is preserved or applied. Already-stored photos keep their EXIF unless a one-off backfill runs. The `photos` table has no JSON column and migrations are parked (#140), so recording the uploader device id needs another place (e.g. a side record or the `url`) or this bullet is parked. HEIC is not accepted.
