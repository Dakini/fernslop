# [otel] Backend: OpenTelemetry tracing with service name, environment and version
**What:** Instrument the FastAPI app (`backend/app/main.py` `create_app()`) with the OpenTelemetry SDK, setting resource attributes `service.name`, `deployment.environment.name` and `service.version`.
**Why:** The user wants telemetry that says which service, environment and deployed version it came from; version comes from `FERNSLOP_IMAGE_TAG` ([#229](done/229-ci-deploy-version-check.md), `app/routers/health.py`), environment from a new `FERNSLOP_ENVIRONMENT` (wired in [#244](244-otel-environment-in-container.md)).
**Edge cases:** No exporter or collector configured (local, tests, today's servers) must not error, block or slow requests, and tests must never export; version is unset locally (use a clear fallback like `unknown`/`dev`, as health does); standard `OTEL_SERVICE_NAME`, `OTEL_RESOURCE_ATTRIBUTES` and `OTEL_SDK_DISABLED` still win; `create_app()` runs once per test, so don't install a global provider or instrument twice.
